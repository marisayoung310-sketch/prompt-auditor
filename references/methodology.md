# Methodology and Attribution

This skill uses an original rubric for prompt inputs. It is inspired by the idea of multidimensional, rule-calibrated, explainable evaluation described by **AlignBench: Benchmarking Chinese Alignment of Large Language Models** from Tsinghua University's THUDM team.

AlignBench evaluates model responses, while Prompt Auditor evaluates the quality of instructions before execution. They are different tasks, datasets, dimensions, and implementations. Never describe Prompt Auditor as an official THUDM product, an AlignBench fork, or a reproduction of AlignBench results.

Project links:

- Repository: https://github.com/THUDM/AlignBench
- Paper: https://arxiv.org/abs/2311.18743

Suggested portfolio wording:

> Inspired by THUDM AlignBench's multidimensional and explainable evaluation methodology, I designed a reusable Codex skill that audits prompts across task types, identifies high-impact ambiguity, and produces a scored report plus a copy-ready revision. The rubric and implementation are original and do not reproduce the official AlignBench benchmark.

When publishing the skill, retain this distinction and cite the AlignBench repository and paper. No AlignBench dataset or model is bundled here.
